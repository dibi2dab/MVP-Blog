## 핵심 수치와 계산식

| 지표 | 값 | 계산식 |
| --- | ---: | --- |
| 월 구독 비용 | 28,000원 | 선택 요금제의 월 구독료 [S1] |
| 연 구독 비용 | 280,000원 | 선택 요금제의 연 구독료(없으면 월 구독료 × 12) [S1] |
| 작업당 비용 | 140원 | 작업당 비용 = 월 구독 비용 / 월 작업 수 |
| 사용 가능 기능 수 | 5개 | 카탈로그에 사용 가능으로 기록된 기능 수 [S1] |
| 기능별 비용 | 5,600원 | 기능별 비용 = 월 구독 비용 / 사용 가능 기능 수 [S1] |
| 월 절감 시간 | 40.0시간 | 월 절감 시간 = 월 작업 수 × 작업당 절감 분 / 60 |
| 절감 시간의 가치 | 1,200,000원 | 절감 시간 가치 = 월 절감 시간 × 시간당 인건비 |
| 시간 절감 순가치 | 1,172,000원 | 시간 절감 순가치 = 절감 시간 가치 - 월 구독 비용 |

## 계산 과정

1. 월 구독 비용 = 28,000원 (Pro 요금제).
2. 연 구독 비용 = 280,000원.
3. 작업당 비용 = 28,000원 / 월 200건 = 140원.
4. 기능별 비용 = 28,000원 / 5개 = 5,600원.
5. 월 절감 시간 = 월 200건 × 12.0분 / 60 = 40.0시간.
6. 절감 시간 가치 = 40.0시간 × 시간당 30,000원 = 1,200,000원.
7. 시간 절감 순가치 = 1,200,000원 - 28,000원 = 1,172,000원.
8. 각 항목을 0~10점으로 정규화한 뒤 QDVI 가중치로 종합한다.
